## Design Context

### Users
Sorgetech operators, developers, and project coordinators who already track work through Excel files on SharePoint. They need to open a project, scan progress, update statuses, notes, and estimates, then sync the workbook without manually editing the spreadsheet.

### Brand Personality
Dense, technical, premium. The application should feel like the existing offer generation software, but more operational: focused, dark, and fast to scan.

### Aesthetic Direction
Dark desktop productivity UI with a persistent sidebar, compact tables, visible status signals, and a clear dirty-save workflow. The interface should prioritize data density and project control over marketing-style presentation.

### Design Principles
- Keep SharePoint configuration familiar to the offer generator.
- Make Excel feel like a structured project board, not a file viewer.
- Show unsaved changes explicitly and sync only when the user chooses Save.
- Keep task editing inline and fast.
- Use calm contrast, compact spacing, and strong status color cues.
